# Plataforma de Gestión de Torneos Deportivos

Sistema integral para torneos multi-deporte (Fútbol, Vóley y Básquet) con sincronización en Google Sheets.

## Estructura del Proyecto
- **`backend/`**: Script de Google Apps Script con caché y plantilla de Google Sheets.
- **`mobile_app/`**: Aplicación móvil Android en Flutter para administradores y mesa de control.
- **`web_portal/`**: Portal web público en React + Vite + Tailwind con diseño estilo "Mundial / Dark Stadium".
